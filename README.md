# MyMindmap

TypeScript + Vite + Mind Elixir で動く、軽量なマインドマップアプリ。バックエンドなし。ブラウザ単体で編集・保存できる。

## 必要環境

- Node.js 20+
- pnpm

## セットアップ

```sh
pnpm install
pnpm dev      # 開発サーバー起動
pnpm build    # 型チェック + 本番ビルド
pnpm preview  # ビルド結果の確認用サーバー
```

## 基本操作

Mind Elixir 標準の編集操作に対応。ノードを選択してから操作する。

| 操作 | ショートカット | ツールバーボタン |
| --- | --- | --- |
| 子ノード追加 | Tab | 子を追加 |
| 兄弟ノード追加 | Enter | 兄弟を追加 |
| ノード削除 | Delete | 削除 |
| 元に戻す | Ctrl+Z | 元に戻す |
| やり直し | Ctrl+Y | やり直し |
| テキスト編集 | ダブルクリック | — |
| ドラッグ移動 | ドラッグ | —（設定で無効化可） |

ツールバーのその他のボタン: 展開切替、全て展開、全て折畳、上へ、下へ、中央表示、全体表示、新規、読込、書出、設定。

## 設定パネル

ツールバーの「設定」ボタンで開く。閉じるボタンまたは Esc で閉じる。「初期値に戻す」で既定値に復元できる。

全13項目（すべてチェックボックス）:

1. アニメーション（`animationEnabled`）
2. ノード登場効果（`appearEffect`）
3. エッジ描画効果（`edgeEffect`）
4. 移動中の既存エッジを薄くする（`dimExistingEdges`）
5. レイアウト移動（`flipEnabled`）
6. フォーカス強調（`focusPulse`）
7. 下位ノードの枠（`subnodeBorders`）
8. 自動保存（`autoSave`）
9. 編集を許可（`editable`）
10. ドラッグ移動（`dragEnabled`）
11. 編集ショートカット（`shortcutsEnabled`）
12. 右クリックメニュー（`contextMenuEnabled`）
13. 編集ツールバー表示（`toolbarVisible`）

親子連動:

- 「アニメーション」をオフにすると 2〜6（登場効果・エッジ描画・既存エッジの薄化・レイアウト移動・フォーカス強調）は無効化される。
- 「レイアウト移動」をオフにすると「移動中の既存エッジを薄くする」も無効化される（選択値は保持）。
- 「編集を許可」をオフにすると 10〜12（ドラッグ移動・編集ショートカット・右クリックメニュー）は無効化される。
- `prefers-reduced-motion: reduce` の環境では設定にかかわらずアニメーションは停止する。

ノード追加時のエッジは、ノード登場開始から100ms後に親から子へ550msで伸びる。Tab / Enter、ツールバー、右クリックメニューの追加操作で共通の演出を使用する。

## キーボードでノードを移動

マウスを使わずにノードの階層・順序を変更できる。移動元ノードを選択して `Ctrl+M`（macOSは `⌘+M`）で移動モードに入り、矢印キーで移動先を選ぶ。

- `Enter`: 選択中ノードの子にする
- `Shift+Enter`: 選択中ノードの前に挿入
- `Ctrl+Enter` / `⌘+Enter`: 選択中ノードの後に挿入
- `Esc`: キャンセル

移動モード中は画面上部に操作案内を表示する。自分自身や自分の子孫には移動できない。既存の `Alt+↑` / `Alt+↓` による兄弟順の入れ替えも利用できる。左右両側レイアウト（`Ctrl+↑`）では、第1階層ノードを選択して `Alt+←` / `Alt+→` で枝ごと左右へ移動できる。すべて「編集ショートカット」設定がONのときに動作する。

既存ノードのレイアウト移動中（400ms）は既存エッジの不透明度を元の25%に抑え、移動完了後に150msで元へ戻す。新規エッジの登場演出やノードの濃さは変更しない。ノードが移動しない操作やReduced Motionでは薄化しない。

「下位ノードの枠」はCentralの孫以降に薄い1px相当の内枠・4pxの角丸を表示する（初期値ON）。Centralと直下ノード、背景、選択アウトラインは変更しない。枠は内側に描画し、ON/OFFでノード寸法・エッジ位置は変わらない。アニメーション・編集のON/OFFと独立して切り替えられる。

## 保存先

- マップ本体: IndexedDB（DB名 `my-mindmap` / ストア `maps` / キー `current`）。形式は `{ version: 1, updatedAt, data }`。
- 設定: localStorage（キー `my-mindmap:prefs:v1`）。
- 自動保存オン時は編集のたびに約400msデバウンスで保存される。オフ時はステータス横の「今すぐ保存」ボタンで手動保存する。

## JSONバックアップ

- 書き出し: ツールバー「書出」で `mindmap-YYYYMMDD-HHMMSS.json` をダウンロードする。
- 読み込み: ツールバー「読込」でJSONファイルを選択する。現在の内容を破棄する前に確認ダイアログが出る。10MB超のファイルは拒否される。
- 「新規」ボタンも現在の内容を破棄する前に確認ダイアログが出る。

## 注意事項

- ブラウザデータを削除するとマップと設定は消失する。重要なマップは定期的にJSONで書き出すこと。
- 複数タブでの同時編集には対応していない。1つのタブで編集すること（タブ間の同期はなく、最後に保存した内容で上書きされる）。
- タブ終了時の自動保存は保証されない。閉じる前にステータスが「保存しました」になっていることを確認すること。

## 対応ブラウザ

IndexedDB、Web Animations API、`matchMedia` に対応した現行の Chrome / Edge / Firefox / Safari を想定。


## 既知の制限

- エッジ描画効果はMind Elixir v5の標準ブランチが対象。独自矢印・サマリー線は対象外。想定外のSVG構造では演出を省略する。
- 大規模マップでは FLIP 対象が200件超の場合にアニメーションが省略される。
- タブ終了時・クラッシュ時の保存は非保証（上記「注意事項」参照）。
